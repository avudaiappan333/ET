# Engada Pochu

Privacy-first Tamil-English money tracker. This branch begins the implementation of the Android and browser app in `feature/production-app`.

- Android package: `com.engadapochu.app`
- Local-only transaction storage; no transaction sync service
- Review before saving recognized or typed entries

Build verification is pending; run `gradle --no-daemon --stacktrace assembleDebug` in a configured Android SDK environment. See the repository workflow for CI.
